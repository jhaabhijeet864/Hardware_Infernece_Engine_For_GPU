## Becoming a Contributor

We celebrate all contributions:
- Adding or validating GPU/accelerator hardware specs.
- Reporting or fixing calculation inaccuracies.
- Enhancing calculator UX, accessibility, and visual presentation.
- Writing documentation, articles, and usage guides.

To add yourself to this list:
1. Submit a meaningful Pull Request (code, documentation, or hardware data).
2. Once merged, add your name and GitHub handle in a follow-up commit or within your PR!
