# Plan 07-03: Factory Test Station GUI & PIN Pairing View

## Goal
Overhaul the desktop user interface in `apps/desktop/src/App.tsx` and accompanying components to serve as a production test station control panel for OEM factory technicians.

## Proposed Changes

### 1. Rig Status & Sensor Dashboard (`apps/desktop/src/App.tsx`)
- Display real-time machine hardware topology:
  - GPU cards list (model, total/used/free VRAM, temperature, power, clock speed).
  - Multi-GPU aggregation cards (e.g. Dual 4090 total pool).
  - Host CPU load and system RAM bar.
  - Gateway connection badge (`CONNECTED`, `STREAMING`, `OFFLINE`).

### 2. PIN Pairing Card (`apps/desktop/src/components/PairingCard.tsx`)
- Display large, high-contrast 6-digit numeric PIN for quick technician pairing.
- Countdown timer for PIN expiration with auto-refresh.
- Instructions for floor technicians scanning via mobile app.

### 3. Local Qualification Quick Launcher & Active Job Monitor
- Workload archetype selector (`Enterprise RAG`, `Customer Support`, `Code Assistant`, `Agentic Reasoner`).
- "Run Local Qualification" button to trigger benchmarks directly from the workstation GUI without waiting for cloud dispatch.
- Active run progress bar displaying live TTFT, ITL, and real-time terminal output stream.
- Prominent 🚨 **Emergency Abort** button for instant manual VRAM purge.

## Verification
- Visual inspection and component tests verifying UI rendering, pairing PIN display, and local job triggering.
