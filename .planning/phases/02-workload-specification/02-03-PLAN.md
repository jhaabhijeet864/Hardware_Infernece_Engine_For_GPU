# Plan 02-03: Feasibility Pre-Check, Benchmark Spec Export & App Integration

## Goal
Connect the Workload Builder into `App.tsx`, compute dual-phase feasibility (Typical P50 vs Stress P99), display transparent pre-check disclaimers, and provide an automated "Export Benchmark Spec" modal allowing users to copy or download `workload-benchmark-spec.json` for Phase 3's CLI runner.

## Proposed Changes

### 1. Dual-Phase Feasibility Display
- In `ResultsDisplay.tsx` and `App.tsx`:
  - Show **Typical Memory (P50)**: Standard operating memory when typical prompt and output lengths are processed.
  - Show **Peak Stress Memory (P99)**: Worst-case VRAM when all concurrent streams hit maximum input/output bounds simultaneously.
  - Show explicit SLA criteria: *"Target: TTFT < X ms, ITL < Y ms"*.

### 2. Implement Benchmark Spec Exporter (`src/lib/engine/exporter.ts`)
- Function `generateBenchmarkConfig(workload: WorkloadSpecification, result: WorkloadEstimationResult)`:
  - Formats JSON specification compatible with `vllm bench serve`:
    ```json
    {
      "version": "1.0",
      "workload_name": "Enterprise RAG & Document QA",
      "model_id": "meta-llama/Meta-Llama-3.1-8B-Instruct",
      "serving_runtime": "vllm",
      "precision": "FP16",
      "cli_command_preview": "vllm bench serve --backend vllm --model meta-llama/Meta-Llama-3.1-8B-Instruct --dataset-name random --random-input-len 3500 --random-output-len 400 --request-rate 8 --save-result",
      "workload": { ... },
      "analytical_estimates": { ... }
    }
    ```
- Add "Export Benchmark Config" button to the header and workload card.
- Toast confirmation using `sonner`.

### 3. App Shell Navigation & Mode Synchronization
- Ensure the main tab bar clearly identifies:
  - **Workload Qualification (Inference)**: Full enterprise workload sizing, feasibility pre-check, and hardware matchmaking.
  - **Fine-Tuning Sizing (Training)**: Experimental full & LoRA training memory estimates with parameter breakdown.
  - **Quantization Trade-offs**: Side-by-side format showdown.

## Verification
- Test exporting `workload-benchmark-spec.json` and verify schema matches `vllm bench serve` CLI syntax.
- Verify `npm test` and `npm run build` pass without warnings.
