# Plan 02-01: Workload Specification Schema & Archetype Presets

## Goal
Define the typed `WorkloadSpecification` schema in `@engine`, implement calculations for prompt/generation token distributions and concurrency scaling, and provide standard enterprise workload archetypes (RAG, Chatbot, Code Assistant, Agentic Reasoning).

## Proposed Changes

### 1. Create `src/lib/engine/workload.ts`
- Define `ServingRuntime`: `'vllm' | 'tensorrt-llm' | 'ollama' | 'tgi'`
- Define `WorkloadSpecification`:
  - `id`: string
  - `name`: string
  - `description`: string
  - `modelId`: string
  - `runtime`: `ServingRuntime`
  - `precision`: `PrecisionFormat`
  - `kvCacheDtype`: `PrecisionFormat`
  - `promptTokensP50`: number
  - `promptTokensP99`: number
  - `generationTokensP50`: number
  - `generationTokensP99`: number
  - `concurrency`: number // Active concurrent streams
  - `registeredUsersEstimated`?: number
  - `targetSla`: {
      maxTtftMs: number
      maxItlMs: number
      minTokensPerSec?: number
    }
- Define `WorkloadArchetype` presets:
  1. `enterprise-rag`: Meta Llama 3.1 8B, vLLM, FP16, Prompt P50: 3,500, Gen: 400, Concurrency: 8, SLA TTFT < 600ms, ITL < 35ms.
  2. `customer-support`: Meta Llama 3.2 3B, vLLM, FP16, Prompt P50: 600, Gen: 150, Concurrency: 32, SLA TTFT < 300ms, ITL < 25ms.
  3. `code-assistant`: Qwen 2.5 14B, vLLM, INT8/AWQ, Prompt P50: 8,000, Gen: 800, Concurrency: 4, SLA TTFT < 800ms, ITL < 30ms.
  4. `agentic-reasoner`: Meta Llama 3.3 70B, vLLM, INT4/AWQ, Prompt P50: 2,048, Gen: 1,500, Concurrency: 2, SLA TTFT < 700ms, ITL < 35ms.

### 2. Add Workload Memory Sizing Calculator
- Implement `calculateWorkloadMemory(workload: WorkloadSpecification)`:
  - Calculates memory at typical workload ($T_{\text{typical}} = \text{Prompt}_{P50} + \text{Gen}_{P50}$)
  - Calculates memory at peak stress workload ($T_{\text{peak}} = \text{Prompt}_{P99} + \text{Gen}_{P99}$)
  - Computes P50 vs P99 KV cache requirements under concurrency $B$.
  - Generates machine-readable `WorkloadBenchmarkConfig` for CLI export.

### 3. Export from `src/lib/engine/index.ts`
- Re-export workload types and presets.

## Verification
- Unit test in `src/lib/engine/__tests__/workload.test.ts` verifying that:
  - Enterprise RAG workload correctly sizes KV cache across 8 concurrent streams at 3,900 tokens.
  - Concurrency scaling is strictly linear for KV cache while weight footprint remains constant.
