# Plan 04-01: Qualification Result Bundle Ingestion & Sample Fixtures

## Goal
Build the qualification result bundle ingestion pipeline: create schema validation in `src/lib/engine/bundle-validator.ts`, prepare standard sample fixtures in `src/lib/fixtures/sample-runs.ts`, and build the `BundleUploader` component with drag-and-drop upload and preset selector.

## Proposed Changes

### 1. Schema Validation & Types (`src/lib/engine/bundle-validator.ts`)
- Import `QualificationRunBundle` definition from `src/cli/bundle-builder.ts`.
- Function `validateQualificationBundle(input: unknown): { valid: boolean; bundle?: QualificationRunBundle; errors?: string[] }`:
  - Validates presence of `metadata`, `environment`, `workload_spec`, `analytical_estimate`, `measured_results`, and `qualification_verdict`.
  - Ensures numeric consistency of percentiles and memory numbers.

### 2. Sample Qualification Fixtures (`src/lib/fixtures/sample-runs.ts`)
- Provide 3 realistic benchmark fixtures:
  1. `enterprise-rag-rtx4090-pass`: Llama 3.1 8B on RTX 4090, 8 concurrent streams, TTFT P95=281ms, peak VRAM=17.8 GiB -> `PASSED`.
  2. `high-concurrency-rtx2050-fail`: Customer Support 3B model on 4GB laptop GPU, 32 concurrent streams, peak VRAM=5.8 GiB -> `FAILED` (Memory Fit & OOM).
  3. `code-assistant-l40s-pass`: Qwen 2.5 14B INT8 on L40S (48GB), TTFT P95=520ms -> `PASSED`.

### 3. Ingestion Component (`src/components/BundleUploader.tsx`)
- Drag-and-drop file dropzone accepting `.json` files.
- File picker button.
- "Load Sample Benchmark Run" dropdown for quick demo and testing without needing to run the CLI first.
- Error banner if an uploaded JSON does not conform to the schema.

## Verification
- Unit test in `src/lib/engine/__tests__/bundle-validator.test.ts` verifying:
  - Valid bundle parses with `valid: true`.
  - Malformed or incomplete JSON yields clear validation errors.
  - All 3 sample fixtures pass validation.
