# Plan 04-02: Analytical vs. Measured Delta & SLA Pass/Fail Comparison View

## Goal
Build the `AcceptanceComparisonView` component in `src/components/AcceptanceComparisonView.tsx` to provide visual side-by-side analysis between theoretical analytical predictions and empirical measured benchmark telemetry.

## Proposed Changes

### 1. Delta Calculations (`src/lib/engine/delta-analysis.ts`)
- Function `computeBenchmarkDeltas(bundle: QualificationRunBundle)`:
  - $\Delta VRAM = |VRAM_{\text{analytical}} - VRAM_{\text{measured}}|$ and error percentage.
  - KV-cache growth delta per stream.
  - TTFT SLA margin: $\text{Margin}_{\text{TTFT}} = \text{Target}_{\text{TTFT}} - \text{Actual P95}_{\text{TTFT}}$.
  - ITL SLA margin: $\text{Margin}_{\text{ITL}} = \text{Target}_{\text{ITL}} - \text{Actual P95}_{\text{ITL}}$.
  - Calibration recommendation based on observed delta.

### 2. UI Comparison Component (`src/components/AcceptanceComparisonView.tsx`)
- **Memory Footprint Comparison**:
  - Analytical estimate vs. Peak measured VRAM bar with delta callout.
  - Idle baseline vs. Active load vs. Available headroom.
- **Latency Distribution vs. Target SLA**:
  - Horizontal bar/range chart showing TTFT P50, P90, P95, P99 against Target Max TTFT line.
  - ITL/TPOT P50, P90, P95, P99 against Target Max ITL line.
- **Service-Level Objective (Goodput) Gauge**:
  - Visual circular or progress bar showing the percentage of requests meeting both TTFT and ITL SLAs.
- **Hardware Telemetry Monitor**:
  - Peak GPU temperature (°C), average power draw (W), and core utilization (%).
