# Plan 04-03: Exportable Hardware Acceptance Certificate & App Integration

## Goal
Build the commercial output component (`src/components/AcceptanceCertificate.tsx`), integrate the 4th top-level tab in `src/App.tsx`, and provide print-ready PDF styling, OEM sign-off blocks, and export buttons for factory delivery acceptance.

## Proposed Changes

### 1. Acceptance Certificate Component (`src/components/AcceptanceCertificate.tsx`)
- High-contrast, publication-grade document layout.
- Document Header: Certificate ID, Timestamp, Hardware Supplier / OEM logo badge.
- Cryptographic Provenance Section:
  - Hardware System SHA-256 Hash (`system_hash`) with copy button and integrity badge.
  - Machine specs table: GPU model, VRAM capacity, PCIe link, driver version, CUDA version, host CPU, RAM.
- Tested Workload Specification:
  - Model ID, precision, context length (P50/P99), concurrency streams, target SLAs.
- Qualification Verdict & 4-Point Audit Checklist:
  - Memory Fit Check (Pass/Fail)
  - TTFT SLA Check (Pass/Fail)
  - ITL SLA Check (Pass/Fail)
  - Reliability & Zero OOM Check (Pass/Fail)
  - Official Stamp: `QUALIFIED FOR DEPLOYMENT` (Green) or `DISQUALIFIED` (Red).
- Physical Delivery Acceptance Sign-off Block:
  - Fields for: Hardware Serial Number, Testing Engineer Name, Organization, Date, and Signature line.

### 2. Export & Print Engine
- CSS `@media print` rules ensuring clean, single-page or two-page PDF formatting without web navigation chrome.
- "Print / Export PDF" button triggering `window.print()`.
- "Download Raw JSON" button downloading `qualification-run.json`.
- "Copy Shareable Link" encoding the run state in URL hash.

### 3. Application Navigation & State Integration (`src/App.tsx`)
- Update `TabMode` type in `src/lib/types.ts` to include `'acceptance'`.
- Add "Acceptance Reports" 4th tab with a dynamic badge indicating whether a physical benchmark run is currently loaded.
- Link Workload Qualification view to Acceptance view via quick-action button.

## Verification
- Run `npm test` verifying all test suites pass.
- Run `npm run build` ensuring complete TypeScript and build integrity.
- Manual test in browser verifying loading sample runs, delta view updates, and certificate print preview.
