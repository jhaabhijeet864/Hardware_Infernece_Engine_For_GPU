# Plan 03-03: CLI Runner Interface & Qualification Result Bundle Generator

## Goal
Build the CLI entrypoint (`src/cli/runner.ts`, `bin/hw-qual.js`) and qualification bundle assembler, allowing an engineer to run `npx hw-qual run --spec workload-spec.json` (or interactive mode), execute the test, evaluate Pass/Fail against SLAs, and output a tamper-evident `qualification-run.json` artifact.

## Proposed Changes

### 1. Qualification Result Bundle Assembler (`src/cli/bundle-builder.ts`)
- Schema: Conforms to `qualification-run.json` schema from `.planning/research/BENCHMARK_ADAPTER_ARCHITECTURE.md`:
  - `metadata`: run_id, timestamp, profile, system_hash
  - `environment`: GPU specs, CPU, RAM, OS, driver, CUDA
  - `workload_spec`: input workload parameters and SLAs
  - `analytical_estimate`: predictions from `@engine` (P50 and P99 bounds)
  - `measured_results`: telemetry watermark (peak VRAM GiB), latency percentiles, throughput
  - `qualification_verdict`:
    - Memory Fit: Pass / Fail
    - TTFT SLA: Pass / Fail (actual P95 vs target max TTFT)
    - ITL SLA: Pass / Fail (actual P95 vs target max ITL)
    - Zero OOM: Pass / Fail
    - Overall: `PASSED` | `FAILED`

### 2. CLI Runner (`src/cli/runner.ts`, `bin/hw-qual.js`)
- Commands:
  - `hw-qual env`: Inspect and print local hardware topology & CUDA capability.
  - `hw-qual run --spec <path>`: Execute benchmark from a JSON specification exported from the web app.
  - `hw-qual run --archetype <id>`: Execute directly against a built-in archetype (e.g. `enterprise-rag`).
  - `hw-qual run --simulate`: Generate a verified synthetic qualification run bundle for testing/pre-sales demonstration without an active GPU.
- Output: Writes formatted JSON to `./qualification_artifacts/qualification-run-<run_id>.json` and prints a summary terminal table with Pass/Fail badges.

### 3. Register in `package.json`
- Add `"bin": { "hw-qual": "bin/hw-qual.js" }`
- Add `"hw-qual": "tsx src/cli/runner.ts"` script.

## Verification
- Run `npm run hw-qual -- env` to confirm system environment detection.
- Run `npm run hw-qual -- run --archetype enterprise-rag --simulate` and verify generation of valid `qualification_artifacts/qualification-run.json`.
