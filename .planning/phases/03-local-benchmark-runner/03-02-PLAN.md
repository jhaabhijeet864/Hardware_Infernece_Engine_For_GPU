# Plan 03-02: Serving Benchmark Adapter & Metrics Parser

## Goal
Implement the benchmark adapter in `src/cli/vllm-adapter.ts` that translates a `WorkloadSpecification` into `vllm bench serve` CLI commands, runs or parses benchmark output artifacts, and extracts granular latency distributions (TTFT, ITL/TPOT), throughput, and reliability metrics.

## Proposed Changes

### 1. Implement vLLM Command Builder & Runner (`src/cli/vllm-adapter.ts`)
- Function `buildVllmBenchCommand(workload: WorkloadSpecification, options?: { host?: string; port?: number })`:
  - Produces exact CLI arguments:
    `vllm bench serve --backend vllm --model <model> --dataset-name random --random-input-len <p50> --random-output-len <p50> --request-rate <concurrency> --num-prompts <N> --save-result --save-detailed`
- Function `executeVllmBenchmark(...)`:
  - Spawns child process for `vllm bench serve`.
  - Concurrently runs `GpuTelemetrySampler` to capture physical VRAM watermark.
  - Waits for benchmark completion or error handling.

### 2. Implement Metrics Parser (`src/cli/metrics-parser.ts`)
- Parse raw JSON output from `vllm bench serve` (and NVIDIA `GenAI-Perf`):
  - Extract TTFT: median, P90, P95, P99 (ms)
  - Extract ITL / TPOT: median, P90, P95, P99 (ms/token)
  - Extract Request E2E Latency: median, P90, P99 (ms)
  - Extract Throughput: requests/sec, generation tokens/sec, total tokens/sec
  - Extract Reliability: total requests, successful, failed, CUDA OOM occurrences.
- Calculate Goodput percentage (requests that satisfied both `TTFT <= SLA` and `ITL <= SLA`).

## Verification
- Unit test in `src/cli/__tests__/adapter.test.ts` with fixtures of actual `vllm bench serve` JSON outputs, ensuring robust parsing of percentiles, throughput, and error boundaries.
