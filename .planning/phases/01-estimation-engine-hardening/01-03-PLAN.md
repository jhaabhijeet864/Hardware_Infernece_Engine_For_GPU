# Plan 01-03: UI Terminology & Scientific Honesty Refactor

## Goal
Update user-facing UI copy, labels, and badges to ensure scientific integrity: replace misleading "GPU Utilization" with "Estimated Memory Occupancy", replace unverified "BEST MATCH" with criteria-based matching badges, add "Experimental" warnings to training/quantization views, and expose model architecture details.

## Proposed Changes

### 1. Update `src/components/GPURecommendations.tsx`
- Replace "Utilization" label with "Estimated Memory Occupancy".
- Replace unconditional "BEST MATCH" tag with explicit criteria:
  - For lowest-cost GPU with `< 85%` occupancy: `Fits Memory (Recommended)`
  - For GPUs with `85%–98%` occupancy: `Tight Margin`
  - For GPUs with `> 98%` occupancy: `High OOM Risk`
- Display both binary GiB and decimal GB where appropriate to avoid memory unit confusion.
- Add footnote: *"Memory occupancy is an analytical estimate. Actual serving performance (TTFT, throughput) requires empirical validation."*

### 2. Update `src/components/ResultsDisplay.tsx`
- Display calculation status pill prominently:
  - `Analytical Estimate` (Cyan badge)
  - `Experimental` (Amber badge, for training mode)
- Add expandable "Assumptions & Architecture" panel:
  - Shows Layer count ($L$), KV heads ($H_{\text{KV}}$), Head dimension ($D_{\text{head}}$), Attention type (MHA / GQA / MLA).
  - Explicit KV cache formula preview: $2 \times L \times H_{\text{KV}} \times D_{\text{head}} \times T \times B \times s$.
- Update breakdowns to explicitly state `GiB` instead of generic `GB`.

### 3. Update `src/components/TrainingCalculator.tsx` and `src/components/QuantizationComparison.tsx`
- Add visible `Experimental` badge at the top of the training calculator panel:
  > *"Training memory estimates are theoretical upper-bounds and vary dramatically based on ZeRO stage, activation checkpointing, and gradient accumulation. Treat these as exploratory guidelines."*
- Clarify in Quantization Comparison that KV-cache quantization has runtime/kernel dependencies and precision quality trade-offs.

### 4. Update Header & Page Metadata (`src/components/Header.tsx`, `index.html`)
- Update subtitle from *"Your ultimate VRAM estimator & GPU matchmaker"* to:
  *"Workload Sizing & Hardware Qualification Engine for Local AI Systems"*
- Ensure branding reflects an engineering-grade qualification instrument rather than a casual estimator.
