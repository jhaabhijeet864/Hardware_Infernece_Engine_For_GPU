# Plan 05-01: Target Machine Matrix & OEM Pilot Profiles

## Goal
Build the OEM and partner hardware configuration matrix in `src/lib/engine/partner-matrix.ts` modeling enterprise workstation and server rigs with known PCIe links, thermal limits, power caps, and recommended concurrency targets.

## Proposed Changes

### 1. Hardware Matrix Registry (`src/lib/engine/partner-matrix.ts`)
- Define `PartnerMachineProfile`:
  - `id`: unique configuration slug (e.g., `dual-rtx-4090-workstation`, `rtx-6000-ada-pro`, `l40s-enterprise-server`, `a100-80gb-datacenter`)
  - `name`: human-readable title
  - `formFactor`: `'workstation' | 'rackmount-server' | 'edge-appliance'`
  - `gpu`: model, count, total VRAM (GiB), PCIe link, power limit (W), thermal throttle limit (°C)
  - `host`: CPU class, recommended RAM (GiB), power requirements (W)
  - `recommendedWorkloads`: list of matching archetype IDs
  - `maxConcurrencyEstimate`: supported concurrent streams without SLA degradation
- Functions:
  - `getAllPartnerProfiles()`
  - `getPartnerProfileById(id: string)`
  - `matchProfileForWorkload(workload: WorkloadSpecification)`

### 2. Unit Tests (`src/lib/engine/__tests__/partner-matrix.test.ts`)
- Verify all partner profiles have valid hardware constraints (positive VRAM, non-zero TDP, PCIe link defined).
- Verify workload matching correctly recommends dual 4090 or datacenter tiers for heavy workloads.
