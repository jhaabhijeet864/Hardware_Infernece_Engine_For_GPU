# Plan 05-03: Factory Pilot Runbook & Production Packaging Distribution

## Goal
Deliver the factory testing runbook (`docs/PARTNER_PILOT_RUNBOOK.md`) and automated factory test station launcher script (`scripts/partner-test-station.bat` and `scripts/partner-test-station.sh`) enabling factory technicians to run automated hardware qualification batches and generate acceptance certificates.

## Proposed Changes

### 1. Factory Pilot Runbook (`docs/PARTNER_PILOT_RUNBOOK.md`)
- **Part 1: Operational Hardware Preparation**:
  - Driver & CUDA verification (`nvidia-smi`, `nvcc -V`).
  - System memory and thermal airflow checklist.
- **Part 2: Running Automated Acceptance Runs**:
  - Step-by-step commands for executing qualification suites against customer workloads.
  - Interpreting the 4-point checklist (Memory Fit, TTFT, ITL, Zero OOM).
  - Remediation protocols for failed runs (thermal throttling, PCIe gen downgrades, VRAM saturation).
- **Part 3: Commercial Pilot Partnership Framework**:
  - Clear terms for OEM partnership (revenue share vs software license, testing costs, warranty liability boundaries, customer relationship ownership).

### 2. Factory Test Station Launchers (`scripts/partner-test-station.bat`, `scripts/partner-test-station.sh`)
- One-click launcher scripts that:
  1. Inspect local machine environment and print hardware fingerprint.
  2. Prompt for target workload archetype or specification JSON.
  3. Execute `hw-qual-cli` benchmark with live telemetry.
  4. Write `qualification-run.json` into `./factory_acceptance_reports/`.

### 3. Verification & Build Integrity
- Test scripts syntax and execution.
- Full project test suite and production build pass.
