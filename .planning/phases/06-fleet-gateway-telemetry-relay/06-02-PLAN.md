# Plan 06-02: PostgreSQL Schema, Drizzle ORM & Persistence Layer

## Goal
Expand the PostgreSQL database schema and establish the Drizzle ORM client in `apps/server/src/db/` to persist physical rig hardware profiles, multi-machine qualification batches, high-resolution telemetry time-series, and delivery certificates.

## Proposed Changes

### 1. Enhanced Schema Definition (`apps/server/src/db/schema.ts`)
- `rigs`:
  - `id`: UUID primary key
  - `name`: string (e.g., "Shenzhen Rig #12 - Dual RTX 4090")
  - `hardwareUuid`: string unique
  - `systemHash`: string (SHA-256 fingerprint from `hw-qual-cli`)
  - `gpuModel`: string
  - `gpuCount`: integer
  - `vramTotalBytes`: bigint/text
  - `driverVersion`: string
  - `cudaVersion`: string
  - `pcieLink`: string
  - `hostCpu`: string
  - `hostRamBytes`: bigint/text
  - `partnerOrg`: string default 'Shenzhen Precision AI Hardware Co.'
  - `isOnline`: boolean
  - `lastHeartbeatAt`: timestamp
  - `createdAt`: timestamp
- `qualificationBatches`:
  - `id`: UUID primary key
  - `name`: string (e.g. "Batch-2026-10-26-4090-Production")
  - `workloadArchetype`: string
  - `targetSlaJson`: jsonb
  - `status`: string ('QUEUED' | 'RUNNING' | 'COMPLETED' | 'FAILED')
  - `dispatchedAt`: timestamp
  - `completedAt`: timestamp
- `qualificationRuns`:
  - `id`: UUID primary key
  - `batchId`: UUID foreign key to `qualificationBatches`
  - `rigId`: UUID foreign key to `rigs`
  - `runId`: string unique
  - `overallVerdict`: string ('PASSED' | 'FAILED')
  - `peakVramGiB`: numeric
  - `ttftP95Ms`: numeric
  - `itlP95Ms`: numeric
  - `goodputPct`: numeric
  - `oomCount`: integer
  - `bundleJson`: jsonb
  - `createdAt`: timestamp
- `telemetrySnapshots`:
  - `id`: UUID primary key
  - `runId`: UUID foreign key
  - `rigId`: UUID foreign key
  - `timestamp`: timestamp
  - `memoryUsedGib`: numeric
  - `gpuUtilizationPct`: integer
  - `temperatureC`: integer
  - `powerWatts`: integer

### 2. Database Client Factory (`apps/server/src/db/client.ts`)
- Implement Drizzle database client with postgres connection pool.
- Support mock / in-memory memory storage mode when `DATABASE_URL` is not provided (allowing tests and local standalone development without requiring an active PostgreSQL daemon).
